# بوابة ركائز للموظفين

موقع مستقل جاهز للرفع إلى مستودع GitHub Pages منفصل، ويستخدم نفس مشروع Firebase الخاص بنظام الإدارة.

## قبل التشغيل

1. فعّل **Anonymous Authentication** من Firebase Authentication > Sign-in method.
2. أضف نطاق GitHub Pages الجديد إلى Authorized domains.
3. ارفع محتويات هذا المجلد إلى جذر المستودع الجديد.
4. تأكد أن قواعد Realtime Database وStorage تسمح للمستخدم المجهول الموثق بالوصول المطلوب فقط. يفضّل وضع قواعد محكمة قبل الاستخدام الفعلي.

يدخل الموظف باستخدام رمز دخول البصمة الذي ينشئه مسؤول الموارد البشرية.
